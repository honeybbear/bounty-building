# Verification Checklist

Every candidate clears EVERY box or the Verifier rejects it. No exceptions.

- [ ] **Real program.** Named administrator, company, or agency — found via web
      search today, not from memory.
- [ ] **Real deadline.** Exact claim-filing deadline confirmed on the official
      program/settlement page. "Ongoing" is acceptable only if the page says so.
- [ ] **Real claim URL.** The official claim-filing page, copied verbatim from
      the program site or a reputable roundup linking to it. Never guessed.
- [ ] **Real eligibility.** Who qualifies, in plain words, from the official terms.
- [ ] **Real value.** Payout/benefit as stated by the program (ranges OK if the
      program states a range; pro-rata shares labeled as estimates).
- [ ] **Proof tier honest.** none | email-code | records | notice-id — whichever
      the program actually requires.
- [ ] **No pay-to-claim.** The user never pays money up front to file.
- [ ] **No attestation fraud.** Nothing about this opportunity requires the user
      to claim something untrue. When in doubt, reject.

Record the source URL and check date in FINDS.md for every accepted find.
